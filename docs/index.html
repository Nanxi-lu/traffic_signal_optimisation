Traffic Signal Optimisation

Can retiming traffic lights cut congestion without making any direction worse? This project tests that on a simulated road with three signalised junctions.

Code on GitHub Full methodology Related: Liverpool bus panel

In plain words

  • I tested three timing plans for the same road on the same 30 simulated evening rush hours.
  • The best plan cut the average wait by 8.6 seconds at each junction a car passes through.
  • But eastbound drivers waited 2.9 seconds longer, which broke the 2-second fairness limit I set at the start.
  • A follow-up search that checked fairness against the original plan found a timing that saves 10.5 seconds and keeps every direction within the limit.
  • The same search for the morning peak found no such timing, so a small trade-off remains there.

1. The problem: a gain with a hidden cost

Evening peak. The Integrated plan compared with the original plan (Phase 3A).

A better network average does not mean every driver is better off.

2. The fix: Phase 4H

Why it happened. The search that produced the Integrated plan only checked fairness against an intermediate plan (Phase 4E), which had already added about 1.3 seconds for eastbound drivers. Small increases added up. What changed. Phase 4H ran the same search again, but compared every option with the original plan, and was tested on 30 new simulated rush hours it had never seen.

5. How it was built

Traffic
A simulated day of traffic counts with morning and evening peaks.
Light timings
Webster's method sets cycle length and green time; offsets line junctions up so cars hit green waves.
Simulation
Individual cars queue at each junction and leave one every 2 seconds on green.
Fair testing
Every plan faces the same 30 random traffic patterns. Plans are chosen on one set and tested on another.

Keep in mind

  • The traffic is simulated, not counted on a real road.
  • The model is simplified: no turning traffic, pedestrians or queues blocking back to the previous junction.
  • The results show the method, not settings for a real road.
